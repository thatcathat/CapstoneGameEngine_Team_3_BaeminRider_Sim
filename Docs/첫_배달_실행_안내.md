# 타이틀·게임 씬과 첫 배달 실행 안내

> 이후 사용자 확인으로 첫 배달의 정상 동작이 확인되었다. 현재 고정 시험 주문은 여러 주문 후보 방식으로 확장되었으며, 최신 내용은 [주문 후보 개발 안내](주문_후보_개발_안내.md)를 따른다. 아래 최초 구현·검증 기록은 당시 기준이다.

## 현재 제작 범위

- 타이틀: `Assets/_Game/Scenes/TitleScene.unity`
- 게임: `Assets/_Game/Scenes/GameScene.unity`
- 타이틀의 ‘배달 시작’ 버튼에서 게임 씬으로 이동한다.
- 작은 동네, 음식점, 고객, 일반 주민, 도보 캐릭터와 3인칭 카메라를 구성했다.
- 시험 주문 수락, E로 음식 수령, 해당 고객과 충돌하여 전달하는 코드를 연결했다.
- 일시정지, 계속하기, 타이틀 복귀, 첫 배달 반복 기능을 연결했다.
- 기존 `Assets/Scenes/Title.unity`와 `SampleScene.unity`는 보존했다.
- 빌드 씬 목록 첫 두 항목에 새 타이틀·게임 씬을 등록했다.

현재 단계는 첫 배달 동작 검증용이다. 지도 후보 선택, 타이머, 보상·경제, 사고·도난, 자전거, 저장은 후속 제작 범위다. 타이틀의 시작 버튼은 항상 새 시험 플레이를 시작한다.

## 실행 순서

1. `TitleScene.unity`를 열고 Play를 누른다.
2. ‘배달 시작’을 누르고 게임 씬에서 ‘주문 수락’을 선택한다.
3. WASD로 이동하고 마우스로 시점을 돌린다.
4. 왼쪽 음식점 앞 노란 표시로 이동한다. ‘E 음식 수령’ 안내가 나타나면 E를 누른다.
5. 음식을 받은 뒤 민트색 ‘배달 고객’ 주민에게 부딪힌다.
6. 배달 완료 화면에서 ‘한 번 더 배달’을 선택할 수 있다.
7. Esc로 일시정지하고 계속하기 또는 타이틀 복귀를 선택한다.

타이틀의 ‘게임 종료’는 에디터에서 Play 모드를 종료하고 실행 파일에서는 앱을 종료한다. 에디터의 Pause가 켜져 있다면 해제해야 플레이할 수 있다.

## 검증 상태

확인한 항목:

- 최초 구현의 Unity 컴파일 성공.
- 새 타이틀·게임 씬의 저장과 빌드 씬 등록.
- 시작 버튼 콜백을 통한 GameScene 전환.
- 타이틀 버튼의 UI 레이캐스트 통과와 게임 UI 입력 모듈 연결.
- 타이틀·주문 UI 캡처 및 한글 표시 확인, 확인 당시 텍스트 넘침 없음.
- 가변 글꼴의 가는 표시를 개선하기 위해 Regular 글꼴로 교체하고 씬 저장.
- 비활성 창에서 프레임이 멈추는 문제를 백그라운드 재생으로 해소한 뒤 게임 버튼의 유효 렌더링 깊이 확인.

미완료 항목:

- 실제 키보드 이동·E 수령·물리 충돌 전달을 연결한 전체 자동 플레이 검증.
- 완료 중복 방지, 이탈 복귀, 일시정지 후 타이틀 복귀의 실행 검증.
- Regular 글꼴로 바꾼 뒤 최종 화면 캡처 재검사.
- 실행 파일 빌드와 사람의 조작감 테스트.

전체 플레이 검증은 비활성 창에서 프레임이 멈춰 주문 버튼 검사에서 실패했다. 원인 확인 후 재실행을 요청했지만 실행 승인이 거절되어 최종 통과 여부를 확인하지 못했다. 기존 실패 결과는 `Docs/Verification/first-delivery-checks.json`에 남아 있으며 성공 기록이 아니다.

검증 코드 `PrototypePlayChecks`는 실행 중 백그라운드 재생을 켜고 종료 시 이전 설정을 복원하도록 보완했다. 이 마지막 보완 후 컴파일 상태는 별도로 확인하지 않았다.

## 다음 개발 작업

먼저 위 미완료 플레이 검증을 마무리하고 발견된 문제를 수정한다. 첫 배달 흐름이 통과하면 지도 위 고객 프로필 3개에서 주문 한 건을 선택하는 기능을 제작한다.

## 에디터 제작 도구

`Delivery Rider > Create Missing Prototype Scenes`는 없는 전용 씬만 생성하고 기존 씬을 재생성하지 않는다. 현재 씬에 저장하지 않은 변경이 있거나 Play 중이면 생성하지 않는다. 기존 씬 수정은 별도로 에디터에서 수행한다.

한글 폰트는 Noto Sans 계열을 사용하며 라이선스는 `Assets/_Game/Art/Fonts/OFL.txt`에 포함되어 있다.
