# v0.6 전환 흐름

초기 고정 주문·몸 충돌 전달·구역형 사건에서 구역 순환 배달과 접촉형 연쇄 사건으로 전환했다.

1. 배달: 수동 콜 → 자동 수령 → 수령 시 타이머 → 주먹 전달.
2. 월드: 초기 동네 배치 → 교통 시범 → 4구역 지형·도로·건물.
3. 진행: 하루 정산 → 생활비·인라인 → 저장·다음 날 → 상환 엔딩.
4. 사건: 구역 진입형을 제거하고 오브젝트·콜별 트리거·음식 복구를 연결.
5. 표현: 차량·행인, 사고 이동·몸짓·카메라를 보완.
6. 다음: 고정 사건·콜 변형 → 통합 플레이 확인과 조정.

현재 실행 계획과 상태는 [첫 완성판 계획](구현계획_첫완성판.md)에만 갱신한다. 과거 전환 상세는 반복 기록하지 않는다.
