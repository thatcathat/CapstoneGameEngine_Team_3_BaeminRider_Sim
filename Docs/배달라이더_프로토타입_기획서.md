## 1. 게임 개요

3인칭 3D 로우폴리 배달 시뮬레이터. 플레이어는 달리기로 시작해 하루 동안 콜을 받아 배달하고, 연쇄로 터지는 과장된 돌발상황을 뚫고 수익을 얻는다. 번 돈으로 생활비를 내고 인라인을 사며, 빚을 모두 모으면 한 번에 갚고 엔딩을 본다.

핵심 경험은 다음과 같다.

- 고트 시뮬레이터 같은 과장된 물리. 장애물이 손해이면서 이득도 되는 딜레마 (**확정** 방향, 10/13)
- 스펠렁키처럼 함정이 유기적으로 배치되어 연쇄로 발동하는 억까 (**확정** 방향, 10/13)
- 일차마다 판이 커지는 큰 고정 사건 (**확정**, 10/13)
- 큰길과 함정이 많은 골목 지름길 사이의 선택 (**시험값**)

### 기존 확정 중 유지하는 것

- 주문 포기 기능 없음.
- 음식을 빼앗기거나 떨어뜨려도 반드시 복구 경로가 있다. 추격 회수 또는 재수령으로 해결하며, 놓쳐도 진행이 막히지 않는다. "분실 삭제"는 주문이 실패로 끝나는 분실을 없앤다는 뜻으로 해석하고, 되찾는 과정(수습형 사건)은 유지한다.
- 한 주문의 완료·보상은 한 번만 적용한다.
- 빚 전액 상환 시 엔딩.

## 3. 전체 게임 흐름

**집에서 시작 → 나가면서 하루 타이머 시작 → 1번으로 콜 확인·수락 → 현재 구역 가게에서 수령(배달 타이머 시작) → 다른 구역 문 앞으로 이동 → 받는 사람을 주먹으로 쳐서 완료 → 반복 → 하루 마감(진행 중 콜까지) → 종료 UI → 정산(생활비 → 구매 → 빚 비교) → 다음 날 아침**

- 집에서 나가는 연출과 종료 UI의 모양은 **미정**. 체험판은 첫 콜 화면에서 바로 시작하고 정산 화면만 있다.
- 빚이 모이면 한 번에 갚고 엔딩으로 간다.

## 4. 콜과 배달

### 콜 확인과 수락

- 배달을 끝내도 콜 화면은 자동으로 뜨지 않는다. 주문이 없을 때 1번으로 연다 (**확정**). 날아가는 손님 장면을 보존하기 위함이다.
- 콜 화면에서 두 콜 중 하나를 고른다. 고르는 동안 시간 정지 (**시험값**, 체험판 동작).
- 방금 떠나온 구역은 다음 목적지에서 제외 (**시험값**).
- 지도(M)는 콜 화면과 별도다. 지도를 열어도 시간은 흐른다 (기존 규칙 유지).
- 하루가 끝나면 새 콜 수락을 막는다.

### 주문 상태

| 상태 | 플레이어 행동 | 다음 상태 | 타이머 |
|---|---|---|---|
| 주문 없음 | 1번으로 콜 화면 열기 → 수락 | 수령 전 | 하루 타이머만 |
| 수령 전 | 현재 구역 가게 범위에 들어가면 자동 수령 | 배달 중 | 하루 타이머만 |
| 배달 중 | 받는 사람을 주먹으로 침 | 배달 완료 | 하루 + 배달 타이머 |
| 음식 뺏김·떨어뜨림 | 추격 회수 또는 재수령 | 배달 중 | 배달 타이머 계속 |
| 배달 완료 | 결과 기록·보상 지급 | 주문 없음 또는 하루 정산 | — |

- 수령 방식: 가게 범위에 들어가면 자동으로 수령한다 (**사용자 결정**, 2026-10-14 "우선 자동"). 재수령도 같은 방식이다. 수령 범위 2.8m는 **시험값**.
- 지각 여부는 주문 상태와 별도로 기록한다. 제한시간이 지나도 수령·복구·전달을 계속할 수 있다.

### 배달 완료 판정

다음 조건을 모두 만족한 주먹 타격에서 한 번만 완료한다.

1. 활성 주문이 있다.
2. 해당 주문의 음식을 보유하고 있다.
3. 맞은 상대가 해당 주문의 받는 사람이다.
4. 해당 주문이 아직 완료되지 않았다.

- 다른 행인을 치거나 몸으로 부딪히는 것만으로는 완료되지 않는다.
- 음식이 없을 때 받는 사람을 쳐도 완료되지 않는다.
- 맞은 받는 사람은 날아간다. 날아가도 같은 사람 식별자로 판정하고, 맵 밖으로 떨어지거나 끼면 안전 위치로 복귀시킨다.
- 공룡 탑승 돌진 등 주먹 외 완료 방식은 해당 고정 사건을 채택할 때 정한다 (**제안**).

## 5. 시간과 하루 종료

### 두 종류의 타이머

- **하루 타이머**: 해시계로 표시하고 숫자는 보여주지 않는다 (**확정**). 하루 길이 600초 (**시험값**, 이전 360초).
- **배달 타이머**: 음식을 받는 순간 시작한다 (**확정**). 수령 이후의 사고·복구 시간은 포함한다.
- 배달 마감 안에 완료하면 정시, 넘기면 지각이다. 마감 이후에는 초과 시간을 표시한다.
- 일시정지 메뉴에서는 두 타이머가 함께 멈춘다.

### 하루 종료 처리

| 종료 시점 상황 | 처리 |
|---|---|
| 활성 주문 없음 | 종료 UI → 정산 |
| 수령 전 | 수령과 전달을 마칠 때까지 진행 |
| 배달 중 | 전달 완료까지 진행 |
| 음식 복구 중 | 복구 후 전달 완료까지 진행 |

마지막 주문을 마치면 새 콜 없이 한 번만 정산한다. 초과 근무에 별도 벌금은 없다.

## 6. 보상

**주문 수익 = 정시 또는 지각 보상 + 콜 상황에 따른 증감 + 달성한 요청 사항의 팁**

| 항목 | 값 | 구분 |
|---|---|---|
| 지각 감액 | 유지 | **확정** |
| 지각 보상 비율 | 기본 보상의 60% | **시험값** |
| 기본 보상 등급 | 가까움 3,000 · 중간 4,500 · 멀리 5,500원 (경계 350m·470m, 최소 배달 거리 300m) | **시험값** |
| 제한시간 | 큰길 기준 거리 ÷ 달리기 속도 × 1.5 + 25초 | **시험값** |
| 콜 상황 증감 | 칼시간 +50%(지각 0원) · 급행 2배 · 묶음 +60% · 심부름 +1,000 · 먹튀 놓치면 0원 | **시험값**, 0원 규칙은 **미정** |

- 제한시간을 큰길 거리로 계산하므로 골목으로 가면 시간이 남는다.
- 보상은 완료 시 한 번 지급하고 정산 화면에서 합계를 보여준다.
### 요청 사항과 팁

v0.1의 요청 사항·팁 제도를 유지한다 (**사용자 결정**, 2026-10-14). 10/13에 삭제된 것은 재미용 요청 3종(날아서 와 주세요·흔들지 마세요·던져 주세요)이며, 이 제도 자체는 콜 상황과 함께 둔다.

- 요청 사항은 수락 전에 공개하고 주문 수락과 함께 적용한다.
- 요청 사항 실패는 주문 완료를 막지 않고 해당 팁만 지급하지 않는다.
- 첫 요청 사항 예시: 음식 수령 후 행인과 부딪히지 않으면 팁 지급 (**시험값**). 받는 사람을 치는 완료 타격은 실패로 계산하지 않는다.
- 지각해도 요청 사항을 지켰으면 팁을 받는다.
- 팁 1,000원 (**시험값**). 구체적인 요청 종류는 과장 물리와 연쇄 사건이 많은 v0.6 환경에 맞게 다시 고를 수 있다.

| 트리거 | 콜마다 몇 곳만 켜짐(콜 경로 주변 위주) · 음식을 받은 뒤에만 작동 | 오리 떼 · 닭 · 근육맨 · 물청소 사장님 · 낙하물 · 타이어 · 비둘기 떼 · 비둘기 탈취 · 개 · 고양이 복서 · 인형탈 알바 · 복제 라이더 | 오리·닭 **확정**, 그 밖 **제안** |

| 자리 없는 상황 | 조건·확률로 등장, 지도에 자리 없음 | 화난 사장님 · 쫓아오는 진상 손님 · 러닝크루 길막 | 넣기 **확정**, 규칙 **시험값** |
| 고정 사건 | 일차와 시각으로 발동, 랜덤 트리거와 별개 | 이삿짐 트럭 · 경찰 오인 추격 · 공룡 · 바닥은 용암 | 방식 **확정**, 내용 대부분 **제안** (9절) |
| 콜 상황 | 콜 화면 · 문 앞 도착 · 배달 중 | 칼시간 등 9종 | **시험값** (10절) |
| 통행·장치 | 항상 | 차·택시·버스·킥보드·행인 / 매트리스·환풍기·대포(이득만) | **시험값** |

- 분류 기준 (**확정**, 10/13 사용자): 맨홀 같은 것은 오브젝트로 두어 항상 터지게 한다. 트리거는 오리·닭처럼 피하기 힘들고 항상 나오면 문제가 생기는 것.
- 기준의 해석 (**제안**): 가만히 있고 자리를 알면 피할 수 있으면 오브젝트, 움직이거나 쫓아와서 피하기 어려우면 트리거. 문을 오브젝트로, 물청소 사장님·낙하물을 트리거로 둔 배정은 확인 전이다.
- 회의 원칙 (**확정**, 10/12): 트리거 2종 = 일차별 고정 + 배치된 것. 돌발성은 그날 켜지는 자리를 바꾸는 방식으로 낸다. 중복은 같은 풀 안에서만. 체험판에는 풀 구분이 아직 없다.
- 긴 사건의 방향 (**확정**, 10/13): 대부분 5초 안에 끝나는 단조로움을 해결하기 위해 진상형(목표가 바뀜)과 수습형(되찾아야 진행)을 둘 다 넣는다.
- 고양이 복서 3합 · 근육맨 운동 파트너로 바꾸기, 자리 없는 상황 3종 추가 (**확정**, 10/13 "다 넣어"). 세부 규칙과 수치는 **시험값**.

### 연쇄

- 방향 (**확정**): 하나 피하면 옆에 다음 것, 맞아 날아간 자리에 다음 것. 트리거가 연달아 켜지며 겹치는 억까.
- 체험판 규칙 (**시험값**): 낮게 날아가는 중에도 다른 함정에 걸림 · 콤보 묶음 안의 트리거는 함께 켜짐 · 트리거에 당하면 40m 안 꺼진 트리거 하나가 80%(오브젝트는 30%) 확률로 켜짐 · 가스통은 묶음째 연쇄 폭발.

### 음식 뺏김·복구 (기존 규칙 유지)

- 음식을 빼앗기면 보유 상태를 해제하고 복구 목적지를 표시한다.
- 추격형은 도둑을 쳐서(또는 닿아서) 되찾는다. 도둑이 도주하거나 접근 불가능해지면 가게 재수령으로 전환한다.
- 회수와 재수령 중 하나가 성공하면 나머지 복구 경로를 종료해 중복 획득을 막는다.
- 음식을 잃은 동안 추가 탈취는 일어나지 않는다. 복구 중 배달 마감이나 하루 종료가 와도 복구 경로를 유지한다.

## 10. 콜 상황 (시험값)

방향 (**확정**, 10/13): 재미용 요청은 삭제하고, "돈 더 줄 건데 1초라도 지각하면 돈 안 준다" 같은 상황과 배달 진상, 주소 틀림을 원한다. 칼시간·주소 오입력의 내용은 확정이고, 그 밖의 종류와 확률·배율은 AI가 고른 **제안**이다.

| 상황 | 언제 | 내용 | 체험판 확률 |
|---|---|---|---|
| 칼시간 | 콜 화면에서 보임 | 제때 +50%, 1초라도 늦으면 0원 | 25% |
| 급행 | 콜 화면에서 보임 | 제한시간 ×0.6, 제때 2배 | 15% |
| 묶음 배달 | 콜 화면에서 보임 | 같은 구역 두 집을 차례로, 보상 +60% | 15% |
| 재촉 전화 | 배달 중 18초마다 | 전화 화면이 가운데를 가림, E로 끊거나 6초 뒤 저절로 끊김 | 주문의 25% |
| 주소 오입력 | 문 앞 도착 때 | 같은 구역의 다른 문으로 변경 | 15% |
| 심부름 | 문 앞 도착 때 | 가게에 다녀와야 완료 가능, 시간 연장 · +1,000원 | 15% |
| 걷는 손님 | 문 앞 도착 때 | 통화하며 반대쪽으로 걸어감, 쫓아가 주먹 | 15% |
| 먹튀 | 문 앞 도착 때 | 음식만 채서 도망, 20초 안에 다시 쳐야 돈 | 12% |
| 가짜 수령인 | 문 앞 도착 때 | 둘 중 주문번호가 맞는 쪽이 진짜, 가짜를 치면 음식 들고 도망 | 12% |

칼시간 지각 0원과 먹튀 0원은 "완전한 실패 없음" 원칙과 부딪혀 **미정**이다. 결정 전까지 Unity 기본판은 지각 감액만 적용한다.

## 12. 정산·경제·엔딩

### 정산 순서

1. 배달별 정시·지각과 보상 표시.
2. 오늘 총수익과 배달 건수 표시.
3. 생활비 자동 차감 (**확정** 방식).
4. 선택 구매(인라인 등 업그레이드).
5. 빚 전액이 모였으면 한 번에 상환하고 엔딩. 아니면 다음 날 아침.

### 생활비 부족

현금이 부족하면 현금을 0원으로 하고 부족분만 빚에 추가한다 (**사용자 결정**, 2026-10-14 v0.1 규칙 유지 재확인). 체험판의 "현금만 0원" 처리는 따르지 않는다.

- 차감 후 현금 = max(0, C − F)
- 차감 후 빚 = D + max(0, F − C)
- 현금은 음수가 되지 않는다. 빚이 늘어나는 것만으로 게임 오버가 되지는 않는다.

### 수치

| 항목 | 값 | 구분 |
|---|---|---|
| 빚 | 100,000원 (사용자 "일단 12만 원" 뒤 10만 원으로 시뮬레이션) | **미정** |
| 생활비 | 5,000원 | 방식 **확정** · 금액 **시험값** |
| 인라인 | 8,000원 · 정산 때 구매 · 2일차부터 판매 | 대체 **확정** · 가격 **시험값** |
| 엔딩 | 생활비를 낸 뒤 빚 전액이 되면 일괄 상환 | **확정** |
| 시작 현금 | 0원 | 기존 시험값 |

마지막 경제 시뮬레이션은 골목·고정 사건·콜 상황이 없던 조건이라 재계산이 필요하다. 순서 제안: 사람이 직접 뛴 하루 배달 건수 측정 → 고정 사건 보상 결정 → 빚·보상 한 세트로 재계산.

### 엔딩

빚 상환 완료 문구와 누적 일수·배달 건수를 보여주는 짧은 화면으로 구현한다. 인라인은 한 번만 구매할 수 있고 다음 날부터 적용한다.

### 접촉형 위험물 시범 (구현 기록)

- 2026-10-13: 사용자가 승인한 HTML식 사건 전환의 대표 시범으로 `TrafficPilot`의 문·타이어에 접근/연쇄 활성화 → 예고 → 실제 접촉 → 종료를 적용했다. 기존 Zone 사건을 일괄 교체하지 않는다. 문·타이어는 회차당 접촉 1회만 소비하고, 기본은 다음 주문 및 이탈 후 재활성화하며 시범에서는 8초 및 이탈 조건을 사용한다.
- 서로 다른 접촉형 위험물은 0.35초 이상의 간격으로 후속 충격을 적용할 수 있고, 실제 피격이 8초 안에 이어지면 연쇄로 집계한다. 후속 충격은 기존 속도를 대체하며 무제한 누적하지 않는다. 기존 `IncidentDirector`가 소유한 사고는 덮어쓰지 않고, 도난 추격·음식 상태는 접촉형 사고가 변경하지 않는다. 일반 차량은 기존 재피격 방지 규칙을 유지한다. 지도에서는 새 공격을 보류하고 진행 중 타이어를 종료하며, 일시정지·정산·비활성화 정리를 적용한다.
- 2026-10-14: 새 4구역 맵에 맨홀·수박을 배치했다. 맨홀은 예고 뒤 분출 접촉으로 발사하고, 수박은 착지·지면 접촉 뒤 제한된 조작을 남긴 미끄러짐을 적용한다. 두 오브젝트는 종료 후 10초·4m 이탈 조건으로 재장전한다. 새 대표 도난 구역은 진행 중 추격을 재진입으로 취소하지 않으며, 기존 구역들의 정책은 유지한다. 상세 범위는 [대표 사건 구간 구현](기록/대표_사건_구간_구현.md)을 따른다.
- 시간·충격·배치는 전부 시험값이고 실제 플레이 체감은 미검증이다.

## 15. 프로토타입 완료 기준

- 수락 후 수령하러 가는 동안 배달 타이머가 줄지 않고, 수령 순간부터 진행한다.
- 1번으로 콜 화면을 열고, 현재 구역에서 수령해 다른 구역 받는 사람을 주먹으로 쳐서 완료할 수 있다.
- 행인 타격, 음식 없는 타격, 반복 타격으로 잘못 완료되거나 중복 지급되지 않는다.
- 정시와 지각 배달에서 서로 다른 보상이 한 번만 지급된다.
- 수령 전에는 오브젝트만 터지고 트리거는 작동하지 않는다.
- 연쇄 중에도 주문을 끝까지 완료할 수 있고, 조작 잠김이 남지 않는다.
- 음식을 뺏겨도 추격 회수와 재수령 양쪽으로 복구할 수 있고, 놓쳐도 진행이 막히지 않는다.
- 하루가 끝나면 새 콜을 받을 수 없고, 진행 중 주문 완료 후 정확히 한 번 정산한다.
- 생활비 처리 후 현금이 음수가 되지 않는다.
- 인라인 구매 후 다음 날 속도가 바뀌고, 구매가 중복 결제되지 않으며, 제한시간은 그대로다.
- 빚 전액이 모이면 한 번만 엔딩으로 간다.
- 받는 사람·플레이어가 맵 밖으로 이탈해도 복귀해 주문을 마칠 수 있다.
