# 개발 흐름 안내

2026-10-15 정리. 평소에는 이 문서와 필요한 문서만 읽는다.

## 지금 어디까지 왔나

첫 배달 → 지도·주문·정산 → 사고·음식 복구 → 4구역 맵 → 핵심 루프 전환 → 경제·저장·엔딩 → 사건 배치 → 차량·행인 → 사고 이동·카메라 순으로 구현했다.
현재는 기본 시스템을 연결한 단계이며, 실제 플레이 완성도는 아직 확인이 필요하다.
다음 개발 범위는 이삿짐 트럭 고정 사건 → 주소 오입력·요청 팁 → 통합 플레이 확인과 조정이다.

## 문서 관리

- 방향·현재 상태·다음 단계만 짧게 갱신한다. 코드별 해설, 좌표 목록, 작업 일지, 반복 검증 로그는 추가하지 않는다.
- 확정 규칙과 시험값·제안·미정을 구분한다. 구현 완료와 플레이 검증 완료도 구분한다.
- 세부 구현과 설정값은 해당 코드·자산을 필요할 때 확인한다. MapLayout 데이터는 문서 정리 대상에서 제외한다.
- HTML 프로토타입은 삭제했으며 앞으로 읽거나 참고하지 않는다.
