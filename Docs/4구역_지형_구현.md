# 4구역 월드 개발 흐름

교통 시범 → 4구역 지형 → 가게·문 연결 → 동네 건물 → 곡선 도로 → 전체 차량망 순으로 확장했다.
현재 본 씬은 FourDistrictPrototype이며 타이틀·다음 날 모두 이 씬으로 이어진다.

- 지형·도로·건물 위에 가게 12곳·배달 문 32곳·집과 사건 자리 80곳을 연결했다.
- 도로는 Splines로 편집하며, 도로 표면은 시각용이고 실제 접지는 지형 충돌체를 사용한다.
- 차량은 큰길 차로와 교차로 연결을 따라 운행한다. 골목에는 진입하지 않는다.
- 앞차·장애물·교차로 대기를 처리한다. 플레이어만 감지 후 2초 제동 지연을 적용하며 지도 중에는 즉시 제동한다.
- 10/15 이동속도 2배 조정을 반영했다. 세부 속도는 차량 프리팹과 도로 생성 설정에서 확인한다.

도로 변경 시 사건 자리 → 건물 → 차량망 → 보행자망 순으로 필요한 배치를 갱신한다.
거리표·지도 이미지는 도로 곡선 변경에 자동 동기화되지 않으므로 큰 변경에서는 함께 검토한다.
컴파일·씬 저장·정적 배치 확인 기록은 있으며 실제 통행·교차로 혼잡·카메라 가림·성능은 플레이 확인이 필요하다.
데이터 용도는 [MapLayout](MapLayout/README.md), 행인은 [인도 NPC](인도_NPC_트래픽_구현.md)를 참고한다.
