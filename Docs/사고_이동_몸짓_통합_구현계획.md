# 사고 이동·몸짓 개발 흐름

발사 → 공중 조종 → 벽·바닥 충돌 → 구르기 → 일어나기 → 배달 재개 흐름을 구현했다.
미끄러짐과 연쇄 충격도 같은 이동 흐름에서 처리하며, 끼임·추락은 안전 도로 복귀로 해결한다.

이동과 충돌은 RiderMotor, 외형 몸짓은 RiderReactionVisual, 시점 반응은 ThirdPersonCamera가 담당한다.
현재는 캡슐 임시 몸짓이다. 추후 캐릭터 모델에 실제 래그돌을 연결한다.
복귀해도 주문·음식·지각 상태는 유지한다. 지도 중 사고 물리는 계속되고 일시정지에서는 멈춘다.
속도별 시야각·사고 비행 거리·충격 흔들림과 카메라 가림 처리를 연결했다.

차량 충돌의 튕김 속도 상한은 기존 전속력 정면 충돌 상한 22의 절반인 11로 제한한다. 수평·수직을 합친 속도의 크기만 제한하고 방향은 유지하며, 약한 충돌은 기존 계산을 유지한다. 차량 4종의 최초 충돌과 재충돌에 동일하게 적용한다. 이는 속도 기준이며 비행 거리나 높이를 절반으로 고정하는 규칙은 아니다.

캐릭터 캡슐은 일반 이동·점프·사고 비행·미끄러짐에서 무마찰 재질을 사용한다. 구르기·일어나기에서만 별도 마찰 재질로 전환하고, 다시 공중에 뜨거나 정상 상태로 돌아오면 무마찰로 복구한다. 두 재질은 실행 시 한 번 생성하고 캐릭터 제거 시 해제한다. 구르기 재질의 정지·동적 마찰은 RiderMotor의 `Rolling friction (test values)`에서 조정하며 시작값은 각각 0.6이다. 기존 구르기 감속도 유지한다. 마찰 결합이 Maximum인 상대 재질은 Minimum보다 우선하므로, 그런 표면을 추가할 때 별도로 확인한다.

컴파일·씬 반영은 확인했고 체감은 미검증이다. 다음은 공중 조종·반사·복귀의 자연스러움을 확인하고 모델·효과음·입자 표현을 보완하는 것이다.
