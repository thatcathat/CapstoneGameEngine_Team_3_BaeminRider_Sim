# 사고 이동·몸짓 개발 흐름

발사 → 공중 조종 → 벽·바닥 충돌 → 구르기 → 일어나기 → 배달 재개 흐름을 구현했다.
미끄러짐과 연쇄 충격도 같은 이동 흐름에서 처리하며, 끼임·추락은 안전 도로 복귀로 해결한다.

이동과 충돌은 RiderMotor, 외형 몸짓은 RiderReactionVisual, 시점 반응은 ThirdPersonCamera가 담당한다.
현재는 캡슐 임시 몸짓이다. 추후 캐릭터 모델에 실제 래그돌을 연결한다.
복귀해도 주문·음식·지각 상태는 유지한다. 지도 중 사고 물리는 계속되고 일시정지에서는 멈춘다.
속도별 시야각·사고 비행 거리·충격 흔들림과 카메라 가림 처리를 연결했다.

컴파일·씬 반영은 확인했고 체감은 미검증이다. 다음은 공중 조종·반사·복귀의 자연스러움을 확인하고 모델·효과음·입자 표현을 보완하는 것이다.
