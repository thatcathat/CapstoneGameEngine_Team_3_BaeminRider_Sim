# 10~11번: 음식 도난·복구와 시간 기반 발생

## 구현

- 음식 운반 중 도난 발생 → `FoodLost` 상태. 주문과 제한 시간은 유지하며 음식 없는 고객 충돌은 배달로 인정하지 않는다.
- 추격형: 보라색 도둑에게 부딪히면 회수한다. 도둑은 지정 경로로 이동하며 도주 완료·제한 시간 초과·맵 이탈·삭제·비활성화 시 음식점 재수령으로 전환한다.
- 재수령형: 즉시 음식점으로 안내한다. 음식점에서 E로 다시 받는다. 추격 중에는 도둑을 회수하거나 도주 후 재수령한다.
- 복구 과정에서 주문 시간은 초기화되지 않고, 영업 종료 후에도 마지막 주문을 해결할 수 있다.
- HUD·월드 안내는 도둑 → 음식점 → 고객으로 전환한다. 지도에 도둑 표시와 현재 복구 목적지 연결선을 표시한다.
- 복구가 끝날 때까지 다른 주요 사건을 차단한다. 정산·씬 종료·관리자 비활성화 시 실행과 임시 도둑을 정리한다.
- 지도에서는 도둑과 시간이 계속 움직이고 일시정지에서는 멈춘다.

## 배치

기존 사고 구역 두 곳은 유지한다. `GameScene > Incidents` 아래에 다음을 추가한다.

| 이름 | 위치 | 동작 |
|---|---|---|
| WestTheftZone | (-14, 1.5, 4), 서쪽 가로 도로 | 보라색. 구역 진입 또는 시간 조건으로 추격 도난 |
| NorthReplacementZone | (0, 1.5, 17), 북쪽 세로 도로 | 보라색. 진입 시 음식점 재수령형 |
| SouthTimedTheft | (0, 1.5, -15), 남쪽 세로 도로 | 파란색. 시간 조건으로만 추격 도난 |

도둑 프리팹: `Assets/_Game/Prefabs/FoodThief.prefab`.
도난 설정: `Assets/_Game/Settings/Incidents/TheftChase.asset`, `TheftReplacement.asset`.
도둑은 Rigidbody 기반 지정 경로 이동이며 자동 길찾기·장애물 우회는 아직 없다. 경로가 막혀도 도주 제한 시간이 끝나면 재수령이 가능하다.

## 튜닝

모든 기본값은 테스트 시작값이다.

- `IncidentDirector`: 주요 사건 하루 총 8회, 종료 후 공통 보호 8초.
- 사건 설정 자산: 같은 C# 사건 타입끼리 발생 횟수·대기 상태를 공유한다. CrashMild/Strong은 사고 종류 하나, 두 Theft 설정은 도난 종류 하나로 집계한다.
- 종류별 기본 최대 4회. 사고 종료 후 30초, 도난 해결 후 35초 대기.
- 같은 종류의 변형 자산은 Kind Max Per Day를 같은 값으로 맞추는 것을 권장한다. 선택 후보의 한도와 직전 실행 자산의 대기 시간을 적용한다.
- 트리거별 20초 대기·최대 3회 제한은 구역과 시간 발생이 공유한다. 기존 수치는 보존한다.
- 도둑 속도 3.6, 도주 제한 18초. 추격 시작 시 경로 좌표를 복사하며 설정 자산에는 실행 상태를 기록하지 않는다.

`TimedIncidentScheduler`는 25~40초마다 등록 지점 중 현재 적합한 지점을 하나 골라 발생을 요청한다. 기본 등록 지점은 서쪽 공용 구역과 남쪽 시간 전용 구역이다. 주변 6m, 음식 보유, 사건·복구 여부, 공통/종류별/구역별 제한을 검사한다. 적합한 지점이 없으면 해당 회차를 건너뛰며 요청을 쌓지 않는다.

트리거의 Allow Zone/Allow Timed로 구역 전용·시간 전용·공용을 정한다. 시간 발생에 사용할 지점은 Scheduler의 Sources에도 연결해야 한다. Chance는 선택된 지점에서 한 번 판정하며 실패 시 다른 지점으로 재추첨하지 않는다. 사고를 시간 목록에 추가하면 실제 사고 구역 안에 있는 경우에만 후보가 된다.

추격 지점은 Thief Spawn과 Escape Route를 연결한다. 경로는 도로 위로 배치하고 건물 내부를 가로지르지 않게 한다. 설정 자산의 Recovery Mode에서 추격/즉시 재수령을 선택한다.

설치 메뉴: `Delivery Rider > Install Theft And Timed Incidents`. 기존 구역·경로·설정·스케줄러 수치는 덮어쓰지 않는다.

## 직접 확인 순서

1. 음식을 받은 뒤 서쪽 보라색 구역에 진입한다. 도둑에게 부딪혀 회수하고 고객에게 배달한다.
2. 다시 시작하여 같은 곳에서 도둑을 놓친다. 음식점 안내로 바뀌면 E로 재수령하고 배달한다.
3. 북쪽 보라색 구역에서 즉시 재수령 흐름을 확인한다. 음식이 없을 때 고객 충돌로 완료되지 않아야 한다.
4. 음식을 들고 남쪽 파란색 구역 근처에서 기다린다. 다음 시간 판정에 도난이 발생하는지 확인한다. 앞선 사건의 보호 시간·횟수 제한이 있으면 이번 판정이 건너뛰어질 수 있다.
5. 추격 중 M으로 지도 표시를 확인한다. Esc 일시정지에서는 도둑과 주문 시간이 멈추고, 지도만 열었을 때는 계속 진행되어야 한다.
6. 하루 제한이 끝난 상태에서도 도난 복구 후 배달이 완료되고 한 번만 정산되는지 확인한다.

코드 검토와 컴파일 확인만 수행하며 자동 플레이·입력·화면 캡처는 수행하지 않는다.
