# 개발자 도구 (F1)

2026-10-29 추가. Play 중 F1로 열고 닫는다. 에디터와 Development Build에서만 동작한다.

- 패널을 연 동안 게임은 계속 흐르고 라이더 조작만 멈추며 커서가 풀린다.
- 탭: 플레이어(이동 속도·점프 높이·사고) / 사건(종류별 개수·등장 일차·간격·발동 규칙, 종류별 내부 값) / 교통(차량·보행자 배치, 주행·보행 값) / 하루·경제 / 카메라(3인칭·커브드월드).
- 수치는 연결된 컴포넌트·설정 자산·프리팹의 직렬화 필드에서 자동으로 찾는다(숫자·토글·Vector2, 8개 이하 배열). 새 필드는 코드 추가 없이 나타나며, 한글 이름은 `DevLabels`에 넣는다.
- 반영 시점: 대부분 즉시. 사건 개수·간격·등장 일차는 '사건 다시 배치', 차량·보행자 수는 각 '다시 배치', 하루 길이·인라인 배율은 다음 날부터.
- 저장(에디터 전용): 설정 자산과 프리팹은 바로 기록하고, 씬 값(라이더·카메라·발동 규칙 등)은 Play를 끝낸 뒤 씬에 기록하고 저장한다. 저장하지 않은 변경은 Play 종료·다음 날 이동 때 원래대로 돌아간다. '변경 내역 복사'로 바꾼 값을 텍스트로 남길 수 있다.
- 설치·재연결: `Delivery Rider → Apply Dev Tools` (반복 실행 가능).
- 확인 상태: 컴파일, 씬 설치, 저장 경로 277개 정적 점검까지 완료. 실제 Play 동작은 사용자 확인이 필요하다.
