## 기준과 확인 범위

큰길 10개와 골목 12개의 원본 평면 좌표를 보존했다. 큰길 폭은 원본 8/10m, 골목은 4.5m다. 골목에는 일반 차량을 넣지 않는다. 큰길의 폭과 별도 보도 확보는 실제 지형 제작에서 검토한다.

원본 집의 도로 노드를 좌표 원점으로 삼았다. Unity X=원본 X−원점 X, Z=원점 Y−원본 Y이며 원본 1단위=1m다. HTML의 화면용 회전은 적용하지 않는다. 집 자체의 측면 배치 위치는 원점과 조금 다르며 가게·배달 문도 원본의 도로 측면 이동값을 적용했다.

고도는 실제 지형 자료가 없는 **게임용 제안**이다. A 8m/B 12m/C 0m/D 4m의 참고값에 맞춘 연속 기울기 면을 0~12m로 제한했다. 구역 전체를 같은 높이로 만드는 방식이 아니며 구역 표시는 중심점의 높이다. 기본면 기울기는 약 6.20%, 22개 도로를 1m 이하 간격으로 계산한 최대 종단 경사는 약 6.18%다. 길이는 평면 기준이며 3D 이동 거리는 다르다.

원본 그래프 1,358개 노드가 한 연결망에 속하고 가게 12곳·배달 문 32곳·집이 연결됨을 확인했다. 이는 그래프의 연결 확인이며 Unity 충돌체를 통한 실제 도보 통행 확인은 아니다. PNG를 직접 열어 배치와 글자 잘림을 확인했다.

## 다음 지형 제작에 남은 작업

1. 교차로를 평탄하게 만들고 진입부를 부드럽게 연결한 뒤 최대 경사를 다시 계산한다. 현재 JSON 높이는 **평탄화 전** 초안이다.
2. 교차로와 골목 접점에서 하나의 고도를 공유하고 틈·중복 충돌체·급격한 단차를 제거한다.
3. 보도·가게 입구·배달 문까지 도보 연결을 만든다. 경사에 놓인 문과 장애물은 지역 지면 기준으로 배치한다.
4. 내리막 제동 거리, 정상 너머 시야, 골목 출구 횡단 공간을 확보한다.
5. 도로 형상이 정해진 후 차로와 사건 자리를 배치한다. 첨부 자료의 450곳과 57콤보는 이번 배치도에 일괄 적용하지 않았다.

2026-10-14 후속 제작에서 평탄화와 경사 제한을 적용한 `FourDistrictPrototype`을 생성했다. 이 문서의 0~12m 배치도는 초기안으로 보존하며, 실제 생성 결과는 [4구역 지형 구현](../4구역_지형_구현.md)과 `district_geometry.json`, `district_surface.png`를 기준으로 한다. 현재 지형 높이차는 약 5.433m, 최대 경사는 6.8%다.

- 거리표: `python Tools/build_route_table.py <배달_체험판_3D.html 경로>` → `route_table.json`(가게×문, 문×문 큰길 기준 거리). Unity에는 `Delivery Rider → Apply Zone Calls (M3)`로 가져온다.
- 지면 색 텍스처: `python Tools/build_ground_texture.py <배달_체험판_3D.html 경로>` → `district_ground.png`(도로를 그리지 않은 구역 색만). 지형 `Ground.mat`에 쓰고, 지도 UI는 기존 `district_surface.png`를 쓴다.
