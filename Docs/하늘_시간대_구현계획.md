# 하늘·시간대 구현 계획

2026-10-29 작성. 규칙과 확정 사항은 [기획서 5.1](배달라이더_프로토타입_기획서.md#51-하늘시간대-연출)이 기준이고, 이 문서는 구현 방법과 순서를 정리한다. 아래 수치는 모두 **시험값**이며 이름은 가칭이다.

## 시간 기준

- 낮: `DeliverySession.DayProgress`(0→1). 출발 전에는 0(한낮)에 머물고 마감 시각에 1(일몰)이 된다. 게임 시간을 따르므로 일시정지·콜 화면에서는 멈추고 지도에서는 흐른다.
- 마감 뒤: 연장 근무가 시작된 뒤 지난 시간으로 어스름을 진행한다(0→1, 60초). 다 진행되면 그 밝기를 유지한다. 정산 중에는 마지막 상태로 멈춘다.
- 다음 날은 씬을 다시 불러오므로 한낮에서 다시 시작한다. 저장할 상태는 없다.

## 구성

| 요소 | 내용 |
|---|---|
| 시간대 제어 `DaySky` | 시간 → 해 방향, 태양광 색·세기, 환경광, 안개색, 하늘 셰이더 값, 창문 불빛을 한 곳에서 계산한다. 값은 설정 자산 `DaySkySettings`에 둔다. |
| 하늘 셰이더 | URP 스카이박스. 천정·지평선 그라데이션, 해 원반·광채, 먼 구름층을 그린다. 커브드월드 때문에 보이는 지평선 아래 7~10° 하늘은 지평선 색으로 채운다. |
| 먼 구름층 | 하늘 셰이더 안의 노이즈 구름. 바람 방향으로 흐르고, 노이즈가 시간에 따라 변해 뭉치고 흩어진다. 둥근 덩어리 윤곽과 두께에서 만든 표면으로 가까운 구름과 같은 빛 램프·아랫면 어둡기·테두리 빛을 받는다. |
| 가까운 3D 구름 | 매끈한 몽글 구름 메시 6개 안팎(변형 몇 종을 에디터에서 생성). 고도 85~125m에서 바람 방향으로 흐르고 표면이 노이즈로 천천히 꿈틀거린다. 덩어리별로 부풀어 생기고 꺼져서 사라지며(항상 불투명), 커브드월드에서는 땅 곡률의 40%만 따라 멀리서는 지평선 쪽으로 내려가고 다가와도 크게 솟지 않는다. |
| 해 그림자 | `PilotSun` 그림자를 소프트로 켠다. 보이는 해는 지평선까지 내려가도 빛의 높이는 18° 아래로 내리지 않아 그림자 길이와 화면 밝기를 지킨다. |
| 구름 그림자 | 태양광 라이트 쿠키(반복 무늬)를 바람 방향으로 흘린다(무늬 120m, 세기 0.5). 3D 구름은 그림자 거리(50m) 안에서 실제 그림자를 드리운다. |
| 마감 어스름 | 해가 진 뒤 하늘·빛을 푸른 어스름으로 바꾼다. 최저 밝기 35%에서 멈춘다. 창문·간판 불빛은 건물 모델링을 바꿀 때 추가한다(보류). |
| 개발자 도구 | F1에 '하늘' 탭을 추가한다. 하늘 시각 미리보기(낮 0~1·어스름), 미리보기 속도, 구름 양·바람, 해 그림자 켜고 끄기. 설정 자산 값은 기존 자동 목록으로 나타난다. |

## 시험값 초안

| 항목 | 값 |
|---|---|
| 해 고도 | 출발 65° → 마감 0°, 어스름 끝 -8° |
| 해 방위 | 한낮 남쪽(180°) → 일몰 서쪽(260°). 큰길에서 노을이 보이도록 조정 |
| 빛 높이 하한 | 18°(10°에서는 일몰 무렵 거리 대부분이 그림자에 덮여 올림) |
| 어스름 | 60초에 걸쳐 진행, 빛 세기 0.45(한낮의 약 35%), 그림자 진하기 0.4 |
| 바람 | 방향 +X, 먼 구름층 5m/s 상당, 3D 구름 4m/s |
| 3D 구름 | 6개, 고도 85~125m, 크기 50~85m, 반경 220m, 수명 90~150초, 생성·소멸 20초, 꿈틀거림 크기의 6%·노이즈 2.5칸 |
| 구름 양 | 0.45(0 맑음 ~ 1 흐림) |

## 진행 상황

- 1단계 구현(2026-10-30): `DaySky`(태양광 오브젝트 `PilotSun`), `Settings/DaySkySettings`, F1 '하늘' 탭(시각 미리보기·자동 진행), 메뉴 `Delivery Rider → Apply Day Sky`.
- 2단계 구현(2026-10-30): `Art/Shaders/Sky.shader`·`Art/Materials/Sky.mat`. 게임 카메라를 단색 배경에서 스카이박스로 바꿨다. 천정색·해 크기·구름 양·구름 크기·바람 방향/세기·구름 모양 변화 속도가 설정 자산에 있고 F1 '하늘' 탭에서도 조정된다. 지평선 색은 안개색 그라디언트를 함께 쓴다.
- 3단계 구현(2026-10-30): `PilotSun` 소프트 그림자를 켰다. 벽·바닥에 붙은 납작한 부품(창문·도로면·차선·표시판 1,113개)은 그림자를 만들지 않게 했다. 도로·건물을 다시 만든 뒤에는 `Apply Day Sky`를 다시 실행한다. 일몰 렌더 비교(10·14·18·22°)로 빛 높이 하한을 18°로 올렸다. F1 '하늘' 탭에 해 그림자 켜고 끄기와 그림자 거리(렌더 파이프라인 자산, 저장하면 프로젝트 전체에 적용)를 넣었고, 패널 제목 줄에 프레임 시간을 표시한다.
- 편집기 측정(1920×1080, CPU, 평균): 그림자 끔 약 1.5ms → 켬 약 2.5ms, 납작한 부품 제외 시 한낮 약 1.9ms. 그림자 거리 35m는 효과가 미미해 50m를 유지했다. GPU 비용은 Play에서 프레임 시간으로 확인한다.
- 4단계 구현(2026-10-30): 마감 뒤 게임 시간 60초에 걸쳐 해가 -8°로 지고 하늘·안개·환경광이 푸른 어스름으로, 빛은 푸르고 약하게(세기 0.45, 한낮의 약 35%), 그림자는 옅게(0.4)바뀐 뒤 유지된다. 해 쪽 하늘과 구름에는 잔광 색이 남는다. 게임 시간 기준이라 정산 화면처럼 시간이 멈추면 함께 멈춘다. F1 하늘 미리보기 슬라이더는 출발 → 마감 → 어스름 끝까지 이어진다. 어스름 색은 설정 자산 Inspector, 시간·해 높이·빛 세기·그림자 진하기는 F1에서도 조정한다.
- 5단계 구현(2026-10-30): 씬의 `Clouds`(`CloudField`)가 라이더 주변 반경 220m 안에 3D 구름 8개를 유지한다(처음에는 로우폴리였고 아래 보강에서 바꿨다). 구름은 바람 방향으로 흐르고(먼 구름층 속도의 0.8배, 4m/s), 20초에 걸쳐 디더로 생겨나 90~150초 머문 뒤 같은 방식으로 흩어지고 다른 자리에서 다시 생긴다. 반경을 벗어나면 일찍 흩어진다. 출발할 때는 이미 떠 있는 상태로 시작한다. 메시는 `Art/Clouds/CloudShape_0~3`(설치기가 생성, 같은 크기의 모델로 바꿔도 된다), 셰이더는 `Art/Shaders/Cloud.shader`·`Art/Materials/Cloud.mat`. 색은 먼 구름층과 같은 빛·그늘 두 톤을 쓰고(어스름도 따라감), 140~240m에서 지평선 색으로 녹는다. 커브드월드에서는 구름 하나가 원점 기준으로 통째로 가라앉는다(꼭짓점마다 굽히면 멀리서 세로로 길게 늘어나서). 그림자는 그림자 거리(50m) 안에서만 보이고 F1에서 끌 수 있다. 개수·고도·크기·속도·수명·생성 시간·반경은 F1 '하늘' 탭에서 바로 반영된다.
- 5단계 보강(2026-10-30, 사용자 결정): [AlexStrook/UnlitClouds](https://github.com/AlexStrook/UnlitClouds)(CC0)를 참고해 3D 구름을 매끈한 몽글 구름으로 바꿨다. 원본은 Built-in 파이프라인 surface shader에 테셀레이션, 미리 구운 꼭짓점 색 조명을 써서 그대로 쓰지 않고 방식만 옮겼다. 메시는 큰 덩어리 한 줄에 위쪽 작은 덩어리와 옆쪽 낮은 덩어리를 얹은 매끈한 타원구 묶음(구름당 덩어리 9~15개, 삼각형 1.4만~1.9만 개)이고, 테셀레이션 대신 메시를 촘촘하게 만든다. 꼭짓점 색에는 아랫면과 덩어리 사이 틈을 어둡게 하는 값만 굽고, 조명은 시간대를 따르는 부드러운 빛·그늘 램프로 계산한다. 표면은 노이즈 두 겹(큰 덩어리 + 빠른 잔물결)으로 법선 방향으로 꿈틀거리고, 기울기만큼 법선도 기울여 덩어리에 음영이 생긴다. 테두리에는 하늘을 배경으로 림 빛이 든다. 구름을 키우면서(크기 25~45m → 50~85m, 개수 8 → 6, 고도 70~110m → 85~125m) 노이즈 무늬도 커졌다(무늬는 구름 크기 기준). 꿈틀거림 크기·속도·노이즈 촘촘함·테두리 빛·아랫면 어둡기는 F1 '하늘' 탭에서 조정한다. 메시 생성 방식을 바꾼 뒤에는 메뉴 `Delivery Rider → Rebuild Cloud Shapes`로 다시 만든다.
- 5단계 2차 보강(2026-10-30, 사용자 결정):
  - 구름 곡률 비율: 곡률 0.002를 그대로 따르면 200m에서 100m로 다가가는 동안 구름이 60m 솟아올랐다. 구름은 땅 곡률의 일부(기본 0.4)만 따른다. 같은 구간에서 24m만 오르고, 먼 구름은 여전히 지평선 쪽으로 내려간다. F1 '하늘' 탭에서 조정한다.
  - 생성·소멸: 4×4 디더 페이드는 반투명하게 비쳐 보였다. 이제 메시 두 번째 UV에 덩어리 중심과 순서를 굽고, 셰이더가 덩어리를 중심에서 하나씩 부풀린다. 생길 때는 가운데 큰 덩어리부터, 흩어질 때는 위·옆 작은 덩어리부터 꺼진다. 항상 불투명하고 그림자도 같이 줄고 는다.
  - 먼 구름: 하늘 셰이더의 먼 구름을 셀 노이즈 덩어리로 둥글게 만들었다. 두께로 보는 쪽을 향하고 가장자리에서 바깥으로 기우는 표면을 만들어, 가까운 구름과 같은 부드러운 빛 램프, 두꺼운 가운데 어둡기, 얇은 가장자리 밝기(F1의 테두리 빛·아랫면 어둡기 공유)를 준다.
  - 두 구름 맞추기:
    - 가까운 구름도 보이는 해 방향을 쓴다(빛은 18° 아래로 내려가지 않지만 구름은 지는 해를 따른다).
    - 어스름에는 두 구름 모두 빛 받는 정도가 80%까지 줄어든다.
    - 멀리 녹아드는 색은 지평선 색이 아니라 그 방향의 하늘 그라데이션이다.
    - `DaySky`가 전역으로 넘기는 구름 색을 선형 색공간으로 변환하도록 고쳤다. 전역 색은 머티리얼 색과 달리 변환되지 않아 가까운 구름만 밝게 떠 보였다.
    - 두 구름이 함께 쓰는 그늘색을 조금 밝혔다(0.86 → 0.95).
    - 그늘색이 하늘색(천정·지평선 혼합)이라 올려다보는 아랫면이 하늘색으로 보였다. '구름 그늘의 하늘색 비율'(기본 0.5)을 추가했고, 나머지는 같은 밝기의 회색이다. 구름 빛·그늘색은 이제 `DaySky` 한 곳에서 계산해 가까운 구름(전역 값)과 먼 구름(하늘 머티리얼)에 같이 넘긴다.
- 명지대 씬(2026-10-30): `FourDistrictPrototype_Myeongji`에도 하늘·구름·구름 그림자·해시계를 같은 설치기로 넣었다([명지대 맵 이관](Myeongji_Map_Import.md)).
- 6단계 구현(2026-10-30): `PilotSun`에 구름 그림자 쿠키를 씌운다. `DaySky`가 매 프레임 `Art/Shaders/CloudShadow.shader`로 120m 반복 무늬 한 장(256×256)을 그리고, 바람 방향으로 가까운 구름과 같은 속도(4m/s)로 흘린다. 무늬는 먼 구름층처럼 구름 양을 따르고 모양 변화 속도에 맞춰 뭉치고 흩어진다. 빛을 따라 비추므로 해가 낮아지면 땅 위 그림자가 길게 늘어난다. 어스름에는 다른 그림자처럼 옅어진다(세기 × 0.4). 세기 0.3은 한낮에 거의 보이지 않아 렌더 비교로 0.5로 올렸다. 진하기(0이면 끔)·무늬 크기는 F1 '하늘' 탭에서 조정한다. 쿠키는 커브드월드 Lit 같은 URP 조명 셰이더에 적용되고, 하늘과 3D 구름에는 적용되지 않는다.
- 여섯 단계 모두 컴파일·씬 반영·편집 모드 렌더까지 확인했고 Play 확인 전이다.

## 작업 순서

각 단계마다 컴파일·씬 반영을 확인하고, 실제 모습은 사용자가 Play에서 확인한다.

1. `DaySky`·설정 자산·개발자 도구 '하늘' 탭: 해 이동과 빛·환경광·안개 연동(하늘은 우선 기본 스카이박스)
2. 하늘 셰이더: 그라데이션, 해 원반, 지평선 아래 채움, 먼 구름층
3. 해 그림자 켜기, 성능 비교, 빛 높이 하한·바이어스 조정
4. 마감 어스름
5. 3D 구름: 메시 생성, 구름 셰이더, 생성·이동·소멸
6. 구름 그림자 쿠키

## 주의

- 공유 머티리얼을 Play 중 직접 바꾸면 에디터에서 자산에 값이 남는다. 바꿔야 하면 실행 중 복제본을 만든다(해시계도 같은 방식).
- 해 그림자는 렌더러 1,900여 개가 그림자를 만든다. 개발자 도구에서 켜고 끄며 프레임을 비교하고, 무거우면 그림자 거리 35~40m, 캐스케이드 2로 낮춘다.
- 3D 구름 그림자는 그림자 거리 경계에서 끊겨 보일 수 있다. 그러면 쿠키 위주로 바꾼다.
- 커브드월드 컬링 여유(10°) 밖의 3D 구름이 늦게 나타나는지 확인한다.
- 스카이박스 기반 환경 반사는 하늘이 바뀌어도 자동으로 갱신되지 않는다. 대부분 광택이 낮아 우선 그대로 둔다.
- 미리보기 속도는 하늘만 빨리 돌린다. 게임 전체 시간(`Time.timeScale`)을 바꾸면 세션의 일시정지·콜 화면 시간 정지와 충돌한다.
