# 인도 NPC 개발 흐름

도로 양쪽 인도 경로 생성 → 모서리 연결 → 보행자 배치 → 장애물 회피 → 주먹 피격과 보행 복귀까지 구현했다.
차량과 배달 받는 사람은 별도 시스템이다. 행인 타격으로 배달 완료나 보상이 발생하지 않는다.

행인은 차량처럼 게임 시작 때 프리팹(`Prefabs/Traffic/Pedestrian`)으로 48명을 생성하며, 위치와 외투 색은 실행마다 랜덤이다(플레이어 시작점 10m 안 제외, `randomEachRun`을 끄면 고정 seed). 끊긴 인도에서는 돌아선다. 앞이 막히면 인도 폭 안에서 왼쪽→오른쪽 순으로 우회를 시도한다. 선택한 쪽으로 이동을 마친 후 전진하고, 유지 시간과 통과 거리를 만족하면서 원래 보행선까지의 공간이 비었을 때 복귀한다. 후보 지점뿐 아니라 옆 이동 구간도 검사한다.
2026-10-17 회피 수정: 좌우 이동만으로 막힘 시간이 초기화되지 않게 실제 전진으로 진행 여부를 판단한다. 옆 이동에 필요한 시간과 추가 대기(기존 시험값 1초)를 주고, 전진하지 못하면 아직 시도하지 않은 반대편을 한 번 확인한 뒤 돌아선다. 돌아설 때 현재 옆 위치를 유지해 먼저 뒤로 벗어나고 원래 보행선으로 복귀한다. 피격·보행 재합류·경로 변경에서 회피 상태를 정리한다. 컴파일 확인과 실제 플레이 확인은 구분하며, 벽 앞·마주 오는 행인·양쪽이 막힌 곳·모서리에서 좌우 반복이 사라지고 통과 또는 돌아서기가 되는지 수동 확인이 필요하다.
플레이어가 4m/s 이상으로 몸을 부딪치면 행인이 날아가고, 빠르게 날아간 행인은 다른 행인을 최대 2단계까지 넘어뜨린다. 연쇄로 날아간 행인이 플레이어 쪽으로 빠르게 날아오면 플레이어도 넘어진다. 날아간 행인은 떨어진 자리에서 일어나 가까운 인도까지 걸어가 보행을 이어가며, 맵 밖 추락이나 오래 막힌 경우에만 인도로 바로 옮긴다. 수치는 시험값이다. 차도 횡단과 골목 보행은 아직 없다.
지도에서는 걷고 콜·일시정지·정산에서는 멈춘다. 외형은 임시 모델이며 실제 보행 애니메이션·래그돌은 후속이다.
도로·건물 변경 뒤에는 `Delivery Rider → Apply Pedestrian Network`로 인도 경로와 행인 프리팹을 갱신한다.
컴파일·씬 반영은 확인했고 실제 혼잡·회피·몸 충돌·연쇄·피격 복귀는 플레이 미검증이다.
