# 인도 NPC 개발 흐름

도로 양쪽 인도 경로 생성 → 모서리 연결 → 보행자 배치 → 장애물 정지 → 주먹 피격과 보행 복귀까지 구현했다.
차량과 배달 받는 사람은 별도 시스템이다. 행인 타격으로 배달 완료나 보상이 발생하지 않는다.

현재 행인 48명을 배치하며, 끊긴 인도에서는 돌아선다. 차도 횡단과 골목 보행은 아직 없다.
지도에서는 걷고 콜·일시정지·정산에서는 멈춘다. 외형은 임시 모델이며 실제 보행 애니메이션·래그돌은 후속이다.
도로·건물 변경 뒤에는 `Delivery Rider → Apply Pedestrian Network`로 보행 배치를 갱신한다.
컴파일·씬 반영은 확인했고 실제 혼잡·정지·피격 복귀는 플레이 미검증이다.
