# 인도 NPC 트래픽

- 구현일: 2026-10-14
- 사용자 요청: 현재 도로 양쪽에 확보된 인도 공간을 따라 걸어다니는 NPC 트래픽 추가.
- 상태: 코드 작성·컴파일·4구역 씬 반영과 저장 확인. 실제 플레이 미검증.

## 구현 범위

`PedestrianNetwork`와 `TrafficPedestrian`은 차량 트래픽·배달 받는 사람과 별도 시스템이다. 기존 도로 중심선, 차도 반폭과 인도 폭으로 양쪽 인도 중앙선을 생성한다. 첫 범위는 인도 폭 1.6m 이상인 큰길이며 별도 인도가 없는 골목에는 생성하지 않는다. 지형 높이를 사용하고 새 인도 지형은 만들지 않는다.

차도와 겹치거나 건물·고정 소품에 막히는 부분은 잘라낸다. 가까운 끝점 중 차도·고정 장애물을 통과하지 않고 인도 영역 안에서 연결되는 것만 모서리 경로로 잇는다. 횡단보도·차도 횡단은 이번 범위에 없다. 연결이 없는 구간은 같은 인도에서 방향을 바꾼다. 따라서 모든 구역이 하나의 연속 순환 경로로 연결된 것은 아니다.

현재 생성 결과는 양방향 보행 구간 162개·모서리 연결 88개·NPC 48명이다. 보행 구간 중 다른 인도로 나가는 연결이 없는 75개는 돌아서기 경로를 사용한다. 실제 씬의 건물·소품과 차도 때문에 경로가 여러 조각으로 나뉘며, 도로 수정 후 다시 생성하면 수치가 바뀔 수 있다.

NPC는 방향별로 인도 중앙선에서 조금 비켜 걷고, 앞의 사람·플레이어·고정 물체를 감지하면 멈춘다. 걷는 속도와 짧은 대기 간격을 달리하고 모서리에서 경로 진행과 실제 위치가 벌어지면 따라잡은 후 진행한다. 평소에는 kinematic Rigidbody로 경로를 따르며, 주먹을 받으면 dynamic 물리 이동으로 바꾼다. 착지·감속 후 가까운 빈 보행 경로로 복귀하며 경로 이동과 물리 이동을 동시에 적용하지 않는다.

행인을 때려도 배달 완료·보상·음식 소유 상태는 변경하지 않는다. 지도에서는 보행이 계속되며 일시정지·콜 선택에서는 게임 시간과 함께 멈춘다. 정산에서도 트래픽 갱신을 중단한다. 차량의 기존 장애물 탐색은 보행자를 감지해 정지할 수 있다. 보행 중 kinematic 행인과 kinematic 차량의 피격 연출은 이번에 별도 추가하지 않았다.

현재 외형은 기존 재질을 사용하는 간단한 몸통·머리·얼굴이다. 주먹 피격 시 외형이 회전하는 임시 표현이며 실제 모델의 래그돌·보행 애니메이션은 후속 연결 대상이다.

## 조정과 재생성

- 메뉴: `Delivery Rider → Apply Pedestrian Network`. `FourDistrictPrototype`을 편집 모드에서 열고 실행한다.
- 기존 `Pedestrians` 루트와 생성된 이름의 NPC를 재사용하고 경로·배치를 갱신한다. 초과 생성 NPC는 삭제 대신 비활성화한다. 사용자 객체와 같은 이름이 충돌하면 중단한다.
- `Pedestrians`의 `PedestrianNetwork.population`은 시험값 48이다. 수를 늘린 뒤 메뉴를 다시 실행하면 추가 배치를 시도한다. 인도 여유 공간이 부족하면 목표 수보다 적게 배치한다. 수를 줄이면 재생성 또는 다음 실행에서 초과 NPC를 비활성화한다.
- NPC Inspector에서 걷는 속도(1.1~1.65m/s), 옆 간격(0.35m), 장애물 탐색(1.1m), 주먹 속도·회수 제한시간 등을 조정할 수 있다. 전부 시험값이다.
- `Pedestrians` 루트를 선택하고 Scene 뷰 Gizmos를 켜면 생성된 보행 경로를 볼 수 있다. 도로·건물·소품 배치가 바뀌면 재생성이 필요하다. 실행 중 경로를 다시 굽지 않는다.

## 검증 수준과 사람 손 확인

최종 컴파일 오류 0·경고 0. 생성 코드의 경로 길이·연결 인덱스·연결 끝점 일치를 확인하고, 에디터 API로 경로 수·NPC 수와 씬 저장 성공을 확인했다. Play 모드 진입·자동 입력은 하지 않았다. 실제 동선·접촉·혼잡·피격 복귀는 미검증이다.

1. 인도 양쪽에서 주민들이 서로 다른 속도로 걷고, 차도로 잘못 들어가지 않는지 확인한다.
2. 교차로 모서리와 막다른 구간에서 연결 이동·방향 전환이 자연스러운지 확인한다.
3. NPC 앞에 서서 정지 반응을 확인하고, 지나간 뒤 다시 걷는지 확인한다.
4. 주먹으로 행인을 날린 뒤 빈 인도 경로로 복귀하는지, 주문 보상이 지급되지 않는지 확인한다.
5. 지도·일시정지·정산과 차량 근처에서 트래픽의 시간·정지 정책을 확인한다.

추가 확장 후보는 가벼운 옆걸음 회피, 보행자 횡단과 차량 양보, 플레이어 비행 접촉 반응, 군중 행동, 모델 애니메이션·래그돌이다. 이번 구현에 포함된 기능으로 간주하지 않는다.
