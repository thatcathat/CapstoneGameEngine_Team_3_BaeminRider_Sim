# 인도 NPC 개발 흐름

도로 양쪽 인도 경로 생성 → 모서리 연결 → 보행자 배치 → 장애물 회피 → 주먹 피격과 보행 복귀까지 구현했다.
차량과 배달 받는 사람은 별도 시스템이다. 행인 타격으로 배달 완료나 보상이 발생하지 않는다.

현재 행인 48명을 배치하며, 끊긴 인도에서는 돌아선다. 앞이 막히면 인도 폭 안에서 왼쪽→오른쪽 순으로 비켜 지나가고, 양쪽 다 막힌 채 1초가 지나면 돌아선다.
플레이어가 4m/s 이상으로 몸을 부딪치면 행인이 날아가고, 빠르게 날아간 행인은 다른 행인을 최대 2단계까지 넘어뜨린다. 연쇄로 날아간 행인이 플레이어 쪽으로 빠르게 날아오면 플레이어도 넘어진다. 수치는 시험값이다. 차도 횡단과 골목 보행은 아직 없다.
지도에서는 걷고 콜·일시정지·정산에서는 멈춘다. 외형은 임시 모델이며 실제 보행 애니메이션·래그돌은 후속이다.
도로·건물 변경 뒤에는 `Delivery Rider → Apply Pedestrian Network`로 보행 배치를 갱신한다.
컴파일·씬 반영은 확인했고 실제 혼잡·회피·몸 충돌·연쇄·피격 복귀는 플레이 미검증이다.
